**Student:** Marzhan Askarova

## Project Overview
This project demonstrates basic and advanced functionalities of jQuery, including DOM selection, element dynamic changes, visual effects, sequential animations, and an interactive Accordion Menu mini-project.

## Features
- **Part 1:** DOM element selection by ID/Class/Tag, changing CSS and HTML content.
- **Part 2:** Visibility (`hide/show/toggle`), Fade (`fadeIn/fadeOut`), Slide methods.
- **Part 3:** Adding/removing DOM nodes (`append`, `prepend`, `remove`), updating attributes (`attr`), and handling live input forms (`val`).
- **Part 4:** Basic, sequential, and combined `.animate()` animations.
- **Part 5:** Interactive Mini Project (Accordion Menu).
